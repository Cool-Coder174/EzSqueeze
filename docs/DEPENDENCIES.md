# Dependencies

This document lists required tools and recommended versions for developing and building EzSqueeze.

## Core
- HISE: latest stable (https://hise.audio)
- CMake: 3.15+
- C++17 compiler
  - macOS: Xcode 12+ (Apple Clang)
  - Windows: Visual Studio 2019+ (MSVC)
- Git

## Optional
- JUCE 7.x (for HISE export / native C++ builds)
- Catch2 (for unit tests)
- Python 3.9+ (for tools and scripts)

## Notes
- Ensure Command Line Tools are installed on macOS: `xcode-select --install`
- On Windows, install "Desktop development with C++" workload in Visual Studio.
